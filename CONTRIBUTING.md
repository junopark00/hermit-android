# Contributing to Hermit for Android

Thank you for your interest in Hermit. Bug reports, translations and code changes are welcome.

## Reporting bugs

Open an issue at <https://github.com/junopark00/hermit-android/issues> and include:

- the Hermit version (Android app info, or the APK name), the device model and the Android version;
- the host (Shell or another GameStream host) and its version;
- what you did, what you expected and what happened instead;
- for a crash, the report from the "Hermit closed unexpectedly" dialog (**Copy** or **Share**).
  Check it first and remove anything you do not want to publish, such as host names or addresses.

Please report security problems privately as described in [SECURITY.md](SECURITY.md), not in a
public issue.

## Suggesting features

Open an issue describing the problem you want to solve and how you use Hermit. Features that need a
host extension usually need a matching change in [Shell](https://github.com/junopark00/hermit-shell).

## Sending changes

1. Fork the repository and create a branch from `main`.
2. Clone with submodules (`git clone --recursive`), and build as described in the
   [README](README.md#building-from-source).
3. Keep each pull request focused on one change, and describe what it changes and how you tested it
   (devices, Android versions, host).
4. Run the source checks before you open the pull request:

   ```sh
   python hermit/check-view-types.py
   python hermit/check-strings.py
   python hermit/check-prefs.py
   ```

5. Test on a real device when the change affects streaming, input or the UI.

### Code guidelines

- Follow the style of the surrounding code. Hermit's own features live in
  `app/src/main/java/com/junopark/hermit/hermit/`.
- Code comments, commit messages and documentation are in English.
- Do not modify the third-party code in `app/src/main/jni/hermit-core/` (the `moonlight-common-c`
  submodule and the prebuilt OpenSSL and Opus libraries). Changes to the streaming core belong
  upstream.
- The Java namespace `com.junopark.hermit` is used by the JNI function names in
  `app/src/main/jni/hermit-core/*.c`; do not rename packages without updating them.

### Strings and translations

- Hermit's strings (English and Korean) are generated by `hermit/make_hermit_strings.py`. Edit the
  script and run `python hermit/make_hermit_strings.py`; do not edit the generated
  `hermit_strings.xml` files or `app/src/nonRoot/res/values*/strings.xml` by hand.
- Strings inherited from the upstream project are in `app/src/main/res/values*/strings.xml`.
- Keep placeholders (`%1$s`, `%2$d`, ...) identical in every translation; `check-strings.py` verifies
  this.
